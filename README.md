# Dreamhack

> [Dreamhack](https://dreamhack.io/) 사이트의 강의 및 워게임 문제 풀이를 정리하는 저장소입니다.

## 소개

[Dreamhack](https://dreamhack.io/)은 웹 해킹, 시스템 해킹, 리버싱, 암호학 등 다양한 보안 분야의 강의와 워게임 문제를 제공하는 한국의 해킹 학습 플랫폼입니다.

## 구조

```
Dreamhack/
├── README.md           # 저장소 소개
├── WARGAMELINK.md      # 워게임 문제 링크 모음
└── xxxx_문제이름/      # 각 문제 풀이 디렉터리 (번호_문제이름 형식)
```

## 워게임 문제

각 문제의 링크는 [WARGAMELINK.md](WARGAMELINK.md)에 정리되어 있습니다.

워게임 문제 URL 형식: `https://dreamhack.io/wargame/challenges/xxxx/`

| 번호 | 문제 이름 | 디렉터리 |
|------|-----------|----------|
| 1925 | Wargame Tutorial | [1925_Wargame_Tutorial](1925_Wargame_Tutorial/) |
